Download

Get started in three steps.

Requires Windows 10 22H2 or Windows 11, 64-bit. No installed .NET needed.

  1. Download the ZIP

    Get the ZIP and SHA256SUMS.txt from the latest release.

    Latest release

  2. Check the checksum

    In PowerShell, compare the result with the line in SHA256SUMS.txt.

    Get-FileHash .\TweakPilot-*.zip -Algorithm SHA256

  3. Start TweakPilot.exe

    Unzip, open the folder and start TweakPilot.exe. Choose Install or Try it portable.

Why Windows may warn you: the files are not code-signed yet, so SmartScreen can show "Windows protected your PC". Check the checksum first. Never turn off Defender or SmartScreen for this or any other app.

FAQ

Questions

Is it safe?

Every change is previewed, backed up and reversible. Risky tweaks are hidden unless you switch to expert mode. Still, it changes Windows settings, so read the preview before you confirm.

Will it make my games faster?

Sometimes a little, often not measurably. Each tweak shows whether its effect is proven, small or unclear. There are no FPS promises.

Does it disable Defender?

No. Defender, the firewall, UAC, SmartScreen and Windows Update stay on. The only Defender setting it offers is how much CPU a scheduled scan may use.

Will anti-cheat complain?

TweakPilot does not touch game files or inject anything into games, and security features such as Secure Boot and memory integrity stay on.

Does it collect data?

No. The app sends nothing and only goes online when you click "Check for updates". This website sets no cookies and loads nothing from other servers.

How do I undo?

Open Restore in the app and reset a single tweak, a preset or everything. If a change was interrupted, the app detects it on the next start.

Why is Windows warning me?

The files are not code-signed yet. Check the SHA-256 checksum from the release page before you start the app.
